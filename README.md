# Сайты памяти

Четыре сайта, каждый — **один файл `index.html`**: данные, стили и скрипты внутри.
Ни сборки, ни сервера, ни аккаунтов. Открывается двойным щелчком, работает без интернета.

| Папка | Дизайн |
|---|---|
| `site-1-warm/index.html`  | **«Свет»** — тёплая архивная: кремовая бумага с зерном, портрет в паспарту со сдвинутой подложкой, буквица в биографии, события на вертикальной оси |
| `site-2-noir/index.html`  | **«Ночь»** — кинематографичная: обложка во весь экран с виньеткой, золотые волосяные линии, фотолента с прокруткой вбок и номерами кадров, крупные цитаты |
| `site-3-paper/index.html` | **«Бумага»** — строгая типографика: белый лист, титул во всю ширину, чёрно-белые снимки, ассиметричная 12-колоночная сетка, красные номера разделов |
| `site-4-all/index.html`   | **Все три дизайна сразу** — переключатель в шапке, выбор запоминается |
| `site-5-war/index.html`   | **«Фронт»** — военная тема: тёмный графит, георгиевская лента, красная звезда, узкий уставный шрифт |

## Данные в шаблонах вымышлены

Сайты 1–4 заполнены вымышленным человеком: **Николай Сергеевич Ветров (1951–2024)**,
учитель географии и фотограф. Сайт 5 — **Иван Сергеевич Ветров (1923–2000)**,
старший сержант. Имена, даты, части, награды и подписи к снимкам придуманы,
чтобы показать, как выглядит заполненный сайт. Замените их своими.

**Фотографий и видео в репозитории нет намеренно.** Пока файла нет, на его месте
рисуется генерируемая заглушка с инициалами — шаблон не ломается и выглядит
целым. Кладите свои файлы в `media/` рядом с `index.html` и вписывайте пути
в блоке данных (или загружайте прямо в браузере, см. ниже).

## Сайт 5 «Фронт»

У военного шаблона есть три раздела, которых нет на остальных:

- **Боевой путь** — горизонтальная линия с остановками и датами.
- **Награды** — карточки со звездой: ордена, медали, именные часы.
- **Документы** — крупные сканы с подробным описанием под каждым.
  В отличие от фотоархива, где хватает строки подписи, здесь под снимком
  помещается целый абзац разбора.

## Правка прямо на сайте

Никаких аккаунтов и админок. Внизу справа — кнопка **«Редактировать»** (или `Ctrl+E`).

В этом режиме:

- **любой текст правится по клику** — имя, даты, эпитафия, биография, факты, события,
  подписи фотографий, названия видео, воспоминания, адрес прощания;
- **у каждого блока появляются кнопки** ↑ ↓ ✕ — переставить или удалить;
- **«+ Добавить»** внизу раздела — новый абзац, факт, событие, фото, видео, воспоминание;
- **фотографии** — кнопка «Файл» на снимке или перетаскивание файлов прямо в галерею
  (снимки автоматически ужимаются до 1800 px, чтобы файл не разрастался);
- **портрет и фон обложки** — кнопки под портретом;
- **видео** — в подписи появляются поля «Файл», «YouTube», «Обложка»;
- `Enter` в биографии начинает новый абзац.

Правки сразу сохраняются черновиком в браузере — вкладку можно закрыть, ничего не пропадёт.

Когда всё готово — **«Сохранить файл»** (или `Ctrl+S`). Браузер отдаст готовый `index.html`
со всеми правками внутри: положите его вместо старого — это и есть обновлённый сайт.
Кнопка **«Сбросить»** отменяет черновик и возвращает то, что записано в файле.

> Черновик живёт только в вашем браузере. Пока вы не нажали «Сохранить файл»,
> в самом файле ничего не изменилось и посетители правок не увидят.

Сайт статический: посетители ничего не пишут и не отправляют, форм и комментариев нет.
Всё, что видно на странице, добавляете только вы.

## Правка в текстовом редакторе

Способ для тех, кому привычнее руками. В начале файла — **БЛОК 1 с данными**:

```js
const DATA = {
  name:    "Николай Сергеевич Ветров",
  years:   "1951 — 2024",
  epitaph: "Мир начинается за порогом. Иди и смотри.",
  ...
};
```

| Нужно | Где править |
|---|---|
| Имя, даты, эпитафия, профессия, город | верх блока `DATA` |
| Биография | массив `about` — абзац на строку |
| Таблица фактов | массив `facts` |
| Хронология жизни | массив `timeline` |
| Фотографии | массив `gallery` |
| Видео | массив `videos` |
| Воспоминания | массив `memories` |
| Дата и место прощания | объект `farewell` |
| Названия разделов меню | объект `labels` |
| Цвета и шрифты | **БЛОК 2** в `<style>` (в 4-м сайте — три палитры) |

Блок данных одинаковый во всех четырёх файлах: заполнили один — скопируйте
`const DATA = {…};` целиком в остальные.

## Фото и видео

Два способа. Через кнопку «Файл» в редакторе снимок **вшивается прямо в `index.html`** —
сайт остаётся одним файлом, но тяжелеет (примерно 150–300 КБ на фотографию).

Если снимков много, лучше положить их рядом в папку `media/` и указать путь:

```js
portrait: "media/portrait.jpg",
cover:    "media/cover.jpg",

gallery: [
  { src: "media/foto-01.jpg", caption: "Байкал, мыс Хобой", year: "1994" }
],

videos: [
  { src: "media/jubilee.mp4", poster: "media/jubilee.jpg", title: "Юбилей, 70 лет", text: "Домашняя съёмка." },
  { src: "", youtube: "dQw4w9WgXcQ", title: "Последний урок", text: "Записано выпускниками." }
]
```

Видео в файл не вшивается — только путь или ID ролика с YouTube.

Пока `src` пустой, на месте снимка стоит аккуратная заглушка с годом: сайт можно показывать
родным до того, как собран весь архив.

## Если правите оформление

Файл `build.js` пересобирает три одиночных сайта из `site-4-all/index.html`:

```
node build.js
```

Нужен, только если вы меняете вёрстку или темы и хотите разослать правку по всем сайтам.
**Тексты и фотографии он не трогает** — они у каждого сайта свои.
**Сайт 5 сборка не затрагивает**: у него своя тема и свои разделы, он живёт отдельно.
Темы в мастер-файле размечены комментариями `/* @theme:noir */ … /* @end */`,
сборщик вырезает лишние и убирает переключатель.

## Как выложить в интернет

Любой бесплатный статический хостинг: GitHub Pages, Netlify, Cloudflare Pages.
Залить нужно содержимое одной папки — `index.html` и, если используете, папку `media/`.
